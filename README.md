# 🧘‍♀️ Activity Booking Platform

A full-stack web application that allows organizations to manage and offer **group or private lessons** (e.g., yoga, swimming, judo) across multiple locations. The system enables instructors to register and set availabilities, administrators to manage offerings, and clients to browse and book available lessons.

Built using **Python Flask** for the backend and **HTML/CSS** for the frontend.

## 🎯 Key Features

- Instructor registration with availability across multiple cities
- Administrator-managed offerings for both group and private lessons
- Public lesson catalog with real-time availability
- Booking system for clients with support for multiple reservations
- Guardian support for underage client bookings
- Conflict prevention (e.g., time/location overlap, double booking)
- Concurrency-aware access model for reading and writing data
